# Vibha Sharma — Portfolio Package

## What is included
- `index.html` — complete portfolio page
- `style.css` — responsive visual styling
- `assets/images/profile/vibha.jpg` — current profile image
- `assets/images/case-studies/` — current project thumbnails
- `assets/docs/roadmap-ai-chatbot.pdf` — uploaded AI chatbot roadmap
- `assets/docs/slack-user-market-research.pdf` — uploaded Slack research
- `assets/docs/caesars-operational-dashboard.pdf` — uploaded dashboard PDF
- `assets/videos/` — reserved for the future intro/interview MP4
- placeholders for Figma, Tableau, Power BI, writing, additional case studies, screenshots and video

## Important content model
Future portfolio items are intentionally designed to accept any of:
- external hyperlink (Medium, Substack, ServiceNow Community, Tableau Public, Figma, Loom, YouTube, etc.)
- PDF
- Google Slides / presentation link
- HTML page
- JPG / PNG / WebP screenshot or image
- MP4 video

The current static GitHub version uses local files and links. To add a future item, place its file in the appropriate `assets/` folder and update that card's `href`/image in `index.html`.

## GitHub Pages
Upload the contents of this package to the repository root, keeping the folder structure intact. Then enable GitHub Pages from the repository's Pages settings using the main branch/root folder.

The site does not pretend to have a server-side upload system: the "upload" placeholders are deliberately structured for you to replace with your own curated assets or links in GitHub.
